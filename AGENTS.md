# Agent Configuration & Rules for VillaRentalWeb

## Execution Guidelines
- **Autonomous Execution**: Always execute code edits, file creations, refactoring, bug fixes, and development commands directly without asking the user for confirmation prior to making changes.
- **Direct Implementation**: When a task or change is requested, perform the implementation immediately and report back with the final results and verification.
- **No Approval Prompts**: Do not ask "Should I proceed?", "Would you like me to make these changes?", or wait for user confirmation for standard development actions.
